# Research declarations

This file records the public, deidentified research declarations associated
with the analysis code and aggregate outputs in this repository.

## Funding

This research received no external funding.

## Declaration of competing interest

The authors declare no competing interests.

## Ethics approval and consent to participate

The study used deidentified, publicly available human datasets and involved no
new participant recruitment, intervention, or collection of identifiable human
materials. No additional institutional ethics approval was required for this
secondary analysis of public resources.

## Consent to publish

No identifiable individual data, images, or case descriptions are presented.
Individual consent to publish was therefore not required.

## Data availability

The public data sources used by the analysis are available from their original
providers:

- TCGA-ACC: <https://portal.gdc.cancer.gov/projects/TCGA-ACC>
- GSE19750: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE19750>
- GSE33371: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE33371>
- GSE10927: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE10927>
- GSE49278: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE49278>
- GSE49280: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE49280>

Raw matrices, download archives, and patient-level clinical rows are not
distributed in this repository.

## Code availability

The remote-only analysis, audit, and figure-generation scripts are available in
the `code/` directory. The tested environment and execution order are documented
in `code/README.md`, `code/CODE_MANIFEST.md`, and
`code/requirements-remote.txt`. Raw matrices and patient-level clinical files
are excluded from the code package.

## Acknowledgements

The project acknowledges the public data infrastructures that maintain the
Genomic Data Commons and the NCBI Gene Expression Omnibus resources used in the
analysis.
